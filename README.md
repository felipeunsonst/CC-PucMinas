# 💻 Ciência da Computação — PUC Minas

Este repositório reúne os materiais produzidos ao longo da minha graduação em **Ciência da Computação na PUC Minas**, incluindo trabalhos, projetos, anotações, exercícios e outros registros acadêmicos.

## 📂 Organização

Os conteúdos estão organizados por período da graduação. Em cada pasta há um `README.md` contendo:

- 📚 As disciplinas cursadas no semestre;
- 📄 Os materiais disponíveis para cada disciplina;
- 📊 Um resumo do desempenho obtido nas avaliações, trabalhos e demais atividades.

## ⚠️ Observações

Este repositório foi criado após parte da graduação já ter sido concluída. Por esse motivo, alguns materiais de disciplinas antigas não puderam ser recuperados e, consequentemente, não estão disponíveis.

Sempre que necessário, os arquivos `README.md` de cada período indicam quais disciplinas foram cursadas e quais conteúdos estão ausentes.
